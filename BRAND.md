## Identity

**Name:** TenisX  
**Domain:** tenisx.ai  
**Tagline:** The operating system for tennis  
**Mission:** Everything in tennis is connected.

---

## Design Philosophy

> "A dark-first, AI-native system derived from the TenisX logo — segmented chrome, circuit traces, and glowing nodes that imply everything in tennis is connected."

TenisX is not a calendar app or a booking portal. It is **infrastructure for the sport** — intelligent, networked, alive. Every design decision should feel like it belongs to that system.

**References:** Strava, Apple Fitness+, Whoop, Nike Run Club, Linear (data density)  
**Never reference:** HOA portals, government apps, enterprise SaaS, corporate dashboards

---

## Logo & Wordmark

- The wordmark pairs a clean humanist set with the technological segmented **X**
- The X — chrome packets crossing through illuminated nodes — is the seed of the entire visual system
- App icon: the TX ligature — the X crosses a segmented T-leg (℞ reborn)
- Logo file: `/public/images/TenisX_logo-removebg-preview.png`

### Logo on dark backgrounds
- Use white wordmark on midnight canvas (#0C0F18)
- The X nodes glow in Electric Cyan (#2DE0FF)
- Never place the logo on a light or busy background without a dark overlay

### Logo sizing (mobile)
- Header logo: maintain aspect ratio, minimum 28px height
- Never stretch, recolor, or apply drop shadows to the logo

## Voice & Tone

- **Precision** — exact, confident, no filler
- **Athletic** — performance language, not hospitality language
- **Connected** — surfaces show live data, relationships, signals
- **Never corporate** — no "leverage," "utilize," "synergy"

### UI copy examples
| Wrong | Right |
|-------|-------|
| "Please select a time slot" | "Pick your slot" |
| "Your booking has been confirmed" | "Court 4 is yours" |
| "No results found" | "Nothing here yet" |
| "Error occurred" | "Couldn't connect" |

## Design Metaphors

The visual language draws from:
- **Circuit traces** — thin connecting lines, node dots, routing paths
- **Segmented displays** — the X mark, data chips, mono labels
- **Glow** — cyan halos on live/active state, blue on actions
- **Chrome** — metallic quality in the logo segments

These metaphors should inform illustration, animation, and empty state iconography — not just the logo.

---

## What TenisX Never Is

- A light, pastel, friendly app
- A form-heavy admin portal
- An app with emoji in the UI
- An app with all-caps headlines (eyebrows are all-caps; h1/h2/h3 are not)
- An app with hairline 1px icons
- An app that looks generic on an outdoor court
